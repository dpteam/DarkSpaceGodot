# src/Network/Server

Серверная часть мультиплеера.

**Реализовано (ядро):** авторитарный `GameServer` в `src/Core/Network` — принимает команды,
проверяет принадлежность отправителю, применяет в `WorldSimulation` и рассылает снимки.

**Здесь (слой движка, Этап 4):** хостинг выделенного сервера, реализация `IMessageTransport`
поверх Godot-нетворкинга, лобби, матчмейкинг.

См. ADR-007 в `MEMORY.md`.
