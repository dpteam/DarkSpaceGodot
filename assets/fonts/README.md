# Шрифты

Здесь хранится минимально необходимый набор шрифтов (исключение из правила «всё процедурно»).

Рекомендации (`SCENARIO.md`, раздел «Графика и стиль»):
- **Monospace** для UI, консоли и технических панелей (в духе 0x10c).
- Крупный дисплейный шрифт для заголовков.

До добавления конкретных шрифтов меню, cockpit HUD, карта системы и рынок используют встроенный шрифт Godot.
