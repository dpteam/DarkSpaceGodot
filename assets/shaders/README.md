# Шейдеры

Процедурные шейдеры Godot (GDScript-шейдеры Godot 4) для визуального стиля.

Планируется (`SCENARIO.md`, `MEMORY.md`):
- `planet.gdshader` — планеты (континенты, океаны, льды, лава) на основе `FastNoiseLite`.
- `star.gdshader` — звёзды по спектральному классу (цвет, корона, протуберанцы).
- `nebula.gdshader` — туманности.
- `blackhole.gdshader` — аккреционный диск и гравитационная линза.
- `atmosphere.gdshader` — атмосферный рассеянный свет планет.

> Примечание: шейдеры — единственная допустимая область GDScript/`.gdshader` (см. `AGENT.md`, п. 2.1).
