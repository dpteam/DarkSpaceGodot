# Шейдеры

Процедурные шейдеры Godot (Godot Shading Language) для визуального стиля.

## Реализовано

- `planet_background.gdshader` — фон главного меню: звёздное поле, туманность и процедурная
  планета (FBM-континенты, терминатор, спекуляр по воде, облака, атмосферный ореол, эмиссия).
  Параметры (палитра, радиус, вода/газ, эмиссия, seed) задаются из `MainMenu.cs` по `PlanetType`.

## Планируется (`SCENARIO.md`, `MEMORY.md`)

- `star.gdshader` — звёзды по спектральному классу (цвет, корона, протуберанцы).
- `nebula.gdshader` — туманности.
- `blackhole.gdshader` — аккреционный диск и гравитационная линза.
- `planet_surface.gdshader` — 3D-планета для экрана системы (реальная геометрия + дисплейс).

> Примечание: шейдеры — единственная допустимая область GDScript-подобного кода (язык шейдеров);
> вся логика — на C# (см. `AGENT.md`, п. 2.1).
