# Сторонние аддоны

Сюда устанавливаются сторонние аддоны Godot .NET.

Кандидаты (см. `MEMORY.md` → «Ссылки»):
- **Klotho** — детерминированный нетворкинг.
- **Monke-Net** — клиент-серверный авторитарный нетворкинг.
- **EasySave / Saveable** — сохранения (на текущий момент используется собственная реализация в `src/Core/Data/Save`).

Правила:
- Каждый аддон фиксируется в `MEMORY.md` (что, версия, зачем).
- Запрещено править код аддонов без комментария `// TODO: [TECH]` и записи в `MEMORY.md`.
